# TokenGo introduction video

An 84-second, 1920 × 1080, 30 fps product video with Chinese and English captions. The source uses Remotion; this authoring dependency is separate from TokenGo itself, which needs no Node.js runtime.

The visual direction, claims and shot list are in [BRIEF.md](BRIEF.md). The public outputs are [the MP4](../../docs/media/tokengo-intro.mp4) and [the poster](../../docs/media/tokengo-intro-poster.jpg). All console textures are real captures from an isolated instance with fictional data. They are not evidence of real provider performance.

## Render

Install the locked dependencies with `npm ci`. Supply licensed PingFang SC, Arial and Times New Roman font files as `public/fonts/PingFangSC.ttf`, `Arial.ttf`, and `Times.ttf`; those proprietary font files are intentionally excluded. Generate the original audio with `python3 audio.py`.

Run `npx remotion render src/index.ts TokenGoIntro out/tokengo-intro.mp4 --concurrency=4 --crf=20`. For the SFX-only version add `--props='{"bgm":false}'`. `npm run studio` opens the editable composition. `src/workbench.ts` also provides the shot manifest. The timeline lives only in `src/Main.tsx`.

`render.mjs` is the build-test render driver and uses the browser installed at the explicit `browserExecutable` path. Set CHROME_PATH to your own Chromium executable before using the driver elsewhere. It renders twenty-three QA stills, a music master and an SFX-only audio pass, then remuxes the unchanged picture for the no-music version. The original deterministic score and air effects are generated by `audio.py` without third party samples; they may be reused under the repository license.

## Recapture

The shipped textures may be reused for rendering. To recapture, run an isolated TokenGo demo on a loopback port, create a private JSON file with `origin` and `password` for its `admin` login, then set `DEMO_CREDENTIALS=/path/to/private-demo.json node capture.mjs`. Adjust Chromium's path in that script to the local installation. Never point the capture script at production. It restricts the origin to loopback and checks visible text for common private-address and credential patterns; these checks supplement manual review.

Images are captured at a 1920 × 1080 CSS viewport and 2× resolution. The script preserves the actual DOM layout, replaces fixture endpoint URLs with `api.example.com`, and records element coordinates in `public/textures/layout.json`. The generated fonts, audio, dependencies and render intermediates are excluded from source control.

Revision 2 covers the q18 family-logo onboarding, API/subscription source selection, parameter contracts and outbound proxy policies. Fresh captures are made with `capture-q18.mjs` on build-test; they demonstrate the actual UI with synthetic data, not real subscription login or provider inference acceptance.

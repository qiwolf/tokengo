# 来源与模型兼容维护

已核实、未核实、未充分验收和未实施的版本化范围见[持续核实清单](provider-verification-checklist.md)，随每次版本更新与版本文档一并维护、提交和推送。

兼容规则属于具体来源、上游型号、原生协议、认证线路和版本，不能只看模型品牌。同名模型在官方 API、硅基流动或自部署运行时可能接受不同参数。用途、参数支持、当前账号能否调用、模型清单可见性是独立设置；目录自称支持不等于真实调用已通过。未充分验收只作为状态和范围说明，不作为关闭整个模型、原生接口或已有转换功能的条件；合法请求可以尝试，具体无效参数、权限或无法表达的请求会明确报错。

## 维护与诊断

在管理员面板的“供应商与接入”打开供应商的“管理模型”，进入目标模型“接入设置”，在对应来源的推理设置下打开“兼容诊断与独立验证”。新模型的用途仍通过现有用途维护入口设置，不能用一次探测代替用途选择。对话用途也不能凭模型名自动承诺其支持所有推理档位。

打开诊断只读取本地配置，不联系上游。页面分别显示配置用途、执行种类、推理档位和模式、配置预算、账号状态、字段条件与规则依据；目录值chat的“对话与推理”属于展示用途，不新增执行能力或改变来源身份；保存配置也不会隐式启动外部验证。

普通对话来源的“真实调用验证”另外发送一次所选模型和原生协议的最小请求，可能产生供应方费用。OAuth、独立工具、向量和重排使用“打开现有探针并预填本来源”，核对来源、模型和请求类型后再保存、明确执行；预填不会自动保存或调用。重排输入查询与文档，只检查top-1协议结构、索引范围及有限分数，不证明排序质量。结果绑定本次来源身份，改变模型映射、凭据、协议或相关配置后不能沿用旧成功结果。最小请求通过只证明这一次调用，不证明工具、所有协议、每个推理档位或整个账号都可用。任务有15秒总时限，可以取消；取消不能撤销已经产生的上游用量。任务结果保存在有界内存中，服务重启后不保留成功证明。

“独立读取运行时元数据”只用于显式配置的 Ollama/vLLM，访问其标准 API。不会要求 SSH、开放开发接口或修改第三方后端。采集与生成用途独立，向量和重排来源同样可读取。返回的软件版本、模板或解析器摘要仅为声明候选，不自动写回配置、开启推理能力或替代管理员确认。无法访问也不妨碍保存本地配置。

## 如何理解字段状态

|状态|含义|
|---|---|
|原生支持|匹配的具体合同对该字段有依据；仍不代表当前账号已实测|
|等价转换|当前规则可以保持已声明的字段语义|
|按文档折叠|转换存在已说明的语义差异，例如不同指令层级合并|
|不支持|该形态不能按当前合同执行，应查看具体参数与协议说明|
|尚未确认|未取得足够依据，原生保留字段不代表供应商一定采纳|
|执行器受限|仅增加来源或参数不能补齐所需执行能力|

规则编号是追溯入口，不是模型能力开关。文档证据、合成样本、模拟上游和真实来源调用分别记录。缺少文档原文摘要或型号修订时显示未知，不能把元数据记录的哈希当成原文哈希。

## 参数与历史边界

TokenGo在副本上完成来源适配、默认值、最终合同校验和预算计量，失败不把半成品写入原请求。原生未知扩展原则上保留；涉及预算、历史签名、密文或执行器的未知语义不能靠静默删字段获得成功。

工具 strict 的省略、true、false不能混为一谈；不能为了请求成功而自动降低 true，或修改 schema 使可选字段变必选。角色折叠只用于有依据的前导纯文本形态，无法保持独立优先级时明确说明。签名、密文和完整历史证明不能跨会话、用户、来源或版本混用。

原生请求缺少独立来源上界或未知思考预算时，可采用来源配置、价格配置或既有默认值作为本地预占估算；结果标注origin/confidence，不把Price额度或4096默认值称供应方hard cap。参数类型、协议冲突、鉴权、TPM、账务和实际超额处理继续执行。百炼Responses的合法最小cap16是API形态要求，不表示未知型号已经验收。

缓存读写和推理 token 可能已包含在供应方报告的总量中，不能重复相加。转换响应的 `usage.tokengo_raw_usage` 是有界原始观测，不是价格、供应商账单或新的持久化原报文库。未知用量不当作免费。

MiniMax 转换按具体来源处理 split 形态；工具 strict 保留转换后的原值发给上游，强制执行效果未充分验收，不悄悄降为 false。可表示的 Chat raw 思考历史不因缺少能力声明就整项关闭，仍尊重明确转换开关与历史归属。带签名 Messages、显式 no-split 等无法等价表达的具体请求仍明确拒绝。硅基流动托管结果不能外推为原厂官方 API 已验收。完整实现与验收边界见[核心审计索引](acceptance/2026-10-27-provider-core-audit.md)。

## 运行时声明与降级

高级协议配置中的可选 `runtime_identity` 可以记录运行时版本及精确上游模型的 revision/template/parser/generation_config 摘要；缺项省略，不填写示例值冒充核验。操作者声明和标准 API 声明都不自动成为已验证身份。摘要变化会使相关来源身份和旧默认失效，原配置记录保留。

旧版本程序不能读取非空新字段。降级前备份并用新程序移除受影响来源声明，或保留兼容程序；相关代次与手工默认可能需要重新确认。升级或回滚都不能用旧整库覆盖之后的新会话和账务写入。

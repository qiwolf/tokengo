## 行为与升级边界

recent/detail 的 request 对象新增可空 `channel_name`，来自当前渠道表：改名后显示当前名称，删除后保留渠道 ID和模型；无上游调用时不虚构渠道。`served_model` 仍为选中的逻辑模型，真实上游别名通过 `attempts.upstream_model` 和运行日志查看。历史文件日志不回填。

新程序不会自动改写现有 OpenCode 接入、自定义头或 Nginx。程序与 Web 必须取自同一发行源码；升级前保存数据库、主密钥及配置的一致备份。新增渠道与会话头约定见[供应方接入说明](../provider-channels.md)。回滚切回配套旧程序和页面，不用旧整库覆盖上线后的新账务或会话。公开发布与生产整包升级分别留收据，不移动已发布标签。标签及包内文档保留构建时快照，发布后验收更新在main与GitHub Release说明中，不回写已发布包。

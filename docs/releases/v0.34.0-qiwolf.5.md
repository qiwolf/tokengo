# v0.34.0-qiwolf.5

本版新增部署者智能体的独立运维令牌，让可信智能体通过 HTTP 维护本站，无需共享 root 密码或浏览器会话。Cargo 仍为上游 0.34.0。构建提交、CI 结果、下载附件与镜像摘要以本 Release 实际记录为准。

## 主要变化

- root 在“设置 → 运维令牌”输入名称、有效期并确认当前密码，完整令牌只展示一次；服务端只保存摘要。固定一档 `site_operations`（站点运维）权限，不提供可选 scope、永久有效或自动续期。
- 默认有效90天，可选1–365天；同站点最多20把未到期且未撤销令牌。支持单把撤销和密码复核后全部撤销。普通 root 改名或改密保留独立运维令牌；安全重置会撤销全部 root 会话及运维令牌。
- 新增 `/api/ops/me`、`/api/ops/capabilities` 和 `/api/ops/audit`，分别提供实例与令牌身份、实际动作清单及独立机器审计。当前登记90项 method/path 动作，新增路由默认拒绝机器访问。
- 可管理供应方、渠道、凭据更新、模型、路由、探针、普通用户与业务 Key、价格和预算；诊断仅返回允许的结构化元数据。令牌不能管理 root 安全或再签发令牌，不能读取历史凭据明文、授权/绑定 OAuth、执行原件导出、恢复或整体重置，也不能直接作为 `/v1/*` 推理凭据。
- 撤销与到期后的异步写入被阻止；业务数据库写入与审计关联，审计失败回滚业务写入。诊断屏蔽原始提示词、响应、自由日志、上游错误体及认证资料；若模型目录回显当前凭据，拒绝保存或返回含回显的内容。
- 增加 Python 3 标准库只读接入示例，验证实例身份与实际能力后再调用业务接口；修复撤销后令牌列表即时刷新及控制台页头垂直对齐。

## 接入与权限边界

这是面向部署者信任的智能体的高权限凭据。它能够修改流量目的地、替换供应商凭据、签发业务 Key 和调整费用策略；限制历史密钥 reveal 不等于隔离恶意智能体。探测可能产生供应商费用。按用途分别签发并存入智能体秘密存储，丢失时新建并撤销旧令牌。

本站运维 API 不提供宿主 shell、宿主重启、容器升级、任务编排或发布能力。细粒度 scope 与多档权限仍未实现。完整合同、90项动作表与示例见[运维令牌文档](https://github.com/qiwolf/tokengo/blob/v0.34.0-qiwolf.5/docs/operations-tokens.md)。

## 验证与升级

本地工作区测试969项通过、0失败、2忽略，最终运维专项17项通过；完成 WASM 构建及隔离浏览器的创建、错误密码、关闭后明文移除、撤销状态刷新和安全重置检查。独立部署已验证 root 登录、令牌签发、实例身份、90项能力、业务读取、审计、禁止动作、撤销后401，以及同一源码清单的服务端与前端资产。测试令牌已撤销。本轮不声称所有真实供应商、客户端或 CPU 架构均验收。

本版将数据库 schema37 升为38，新增令牌与实例身份存储。独立部署已核对迁移前的53张表（含SQLite系统表）及原SQL对象保全，迁移后共55张表，完整性与外键检查通过。

升级前成套备份数据库、主密钥、程序、Web和服务配置。WAL数据库须使用 SQLite backup API 或干净停服备份，不可仅复制正在写入的 `.db`。回滚必须恢复与旧程序配套的升级前数据库和其他状态；不能直接用旧程序运行 schema38 数据库，也不能自动丢弃升级后的新写入。升级后已有新业务数据时，先制定数据保全方案再回滚。

## 分发方式

发布流程提供同提交 Linux AMD64 原生包、离线镜像包及 GHCR 版本镜像。可用资产、校验和与镜像摘要以本 Release 实际产物为准，不以本地测试替代公开构建验证。服务端与 Web 必须使用同一发布提交，勿混用旧面板。安装及升级步骤见[原生部署](https://github.com/qiwolf/tokengo/blob/v0.34.0-qiwolf.5/docs/deployment.md)与[容器部署](https://github.com/qiwolf/tokengo/blob/v0.34.0-qiwolf.5/docs/container-deployment.md)。

# v0.34.0-qiwolf.11

本版汇集 qiwolf.10 之后的 Chatbox 订阅兼容、Responses 显式会话和向量/重排真实负载修复。Cargo 仍为 **0.34.0**，数据库 **schema40**。

**已[公开发布](https://github.com/qiwolf/tokengo/releases/tag/v0.34.0-qiwolf.11)并通过独立产物验收。** 发布时间2026-10-23 16:22:46 UTC（北京时间2026-10-24 00:22:46），发行源码 `551f1c1487a1f262725d916cfc3dbfcda874fbe8`。生产此前热修复与本次公开发行分别验收；本轮没有升级生产实例。

## Chatbox 与 Responses

- Chatbox 的开头纯文本 system 提示在订阅 Chat 路径转为上游 instructions；经校验的新增响应配置回显保留于 `provider_metadata.openai_responses`，避免已观测非流式响应被严格转换器误拒绝。通用转换器和原生 Responses 边界保留。[真实 API 验收](../acceptance/2026-10-23-chatbox-system/README.md)涵盖 JSON/SSE 系统指令优先级；未操作 Chatbox 客户端。
- Responses 增加 `client_metadata.session_id` 显式会话识别。`prompt_cache_key` 只用于缓存提示，不能建立或借用会话绑定；它可能随 instructions/tools 改变，也可能在不同会话间共用。携带不透明历史但缺少绑定时明确返回 `explicit_session_required`，保留来源、凭据代次和历史归属保护。旧历史无法凭新标识追认，须新建会话或重新提交可重放历史。[会话合同](../protocols.md)说明优先级与校验边界。
- 已有外部 Hermes 适配器以稳定 `x-session-id` 通过真实 JSON/SSE 两轮工具与不透明历史调用；这是现场客户端独立修复，不随本版网关二进制自动安装。手机聊天端完整用户流程未在该验收中操作。

## 向量与重排

虚拟入口按来源真实能力接收请求，不再用短文本验收样本限制候选数、文本长度或总量。**300 条 × 4096 Unicode 字符是完整验收样本，不是请求上限。** 原文、候选和合法供应商参数保留；不截断文本、不丢候选。类型、结构、维度和返回完整性检查仍有效。向量支持文本、token 输入及 float/base64 输出；重排保留原文并校验候选索引，近同分排序允许合理浮点差异。[能力与配置说明](../vector-model-capabilities.md)列出完整合同。

两个向量端点共用可配置请求传输预算，默认 64 MiB，使用 `TOKENGO_VECTOR_BODY_LIMIT_BYTES` 调整，并须与反向代理一致。该预算属于普通与虚拟调用共同的传输保护；实际 token 窗口由后端决定。现场 BGE-M3 的 **8192 token** 窗口是该模型部署配置，不是所有来源的统一能力。GPU 的明确容量拒绝可在本次请求内继续下一个获准来源，保留完整请求；普通 400/422 不因此泛化重试，也不因单次容量拒绝全局冷却来源。超时、400 拒绝和容量切换日志保留可诊断的安全原因，不记录原文或凭据。

兼容凭证 v4 固定每来源执行两次完整 300 项采样，先检查维度、索引、有限非零数值和归一化，再用有硬边界的来源自身重复噪声校准跨来源距离，同时要求整批平均余弦至少 0.999；不是把所有长文本逐项统一放宽。短文本及日常轻量续验仍逐项要求余弦至少 0.999。旧凭证保持可读，升级失败保留仍有效的既有证据；续验逐来源处理，单个云端失败不阻止已核实健康且身份未变的 GPU 来源。固定采样不靠反复重试挑选通过结果。

### 已有热修复验收与发行边界

已完成的现场热修复采用向量云端优先、GPU 回退，以及重排 GPU 优先、云端回退。300 条完整长文本的公开入口调用、真实容量拒绝后云端承接、隔离实例中真实上游的 503/超时回退、普通用户仅能调用共享入口、账务完成和隔离清理均有本地收据。最终热修复定向检查在 build-test 单次 **402 通过、0 失败**；这不是本版最终发行提交的完整工作区总数。先前完整工作区并发压力两项失败的原断言保留，随后两项各两次串行复核通过，不将其计为四项不同测试。

GPU 使用官方 BGE-M3 tokenizer，修复原分词器对尾空格等输入的 token 差异；17 组边界输入跨来源通过。**官方分词器、GPU 8192 窗口和物理 batch 配置属于现场独立部署变更，升级网关容器或原生包不会自动修改 GPU 后端。** 模型权重和归一化没有借此替换。

冻结中文检索集含 376 条脱敏技术文本、48 个查询，其中 46 个有审定主标签。新向量配新索引的 Recall@10 为 **0.87717**，与历史基线一致；新查询配旧索引的主要召回指标与旧基线相同。新新组合 Hit@1 从 27/46 到 28/46。旧、新运行时与硬件同时不同，不能把变化单独归因于 tokenizer；该集合的未退化结果不代表所有中文语料或客户端验收。私有文本、向量及来源路径不进入公开发行。

现场服务已部署上述热修复，但其后端、前端和外部客户端的阶段性组合，不能视为已安装本版完整正式发行产物。本次发行的服务器、CLI、WASM 和镜像已按同一发行提交重新构建并独立验收。外部调用方曾报告 3 秒超时，长批次应按实际最坏耗时设置等待时间（可从 300 秒评估）；本轮没有读取或修改该调用方配置。

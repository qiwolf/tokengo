# v0.34.0-qiwolf.34 — 模型规格、渠道映射与 Responses

本版提供模型规格目录、渠道模型配置、定价参考值和原生协议设置。程序版本为 `0.34.0-qiwolf.34`，数据库 schema 为 50。

- **模型规格目录**预置 96 条官方型号记录、18 条别名和 19 条已核对的中转差异。添加渠道模型时自动带入规格。管理员可维护上下文窗口、最大输入和用量参考值，权限内的客户端可从 `GET /v1/models` 读取 `specifications`。
- **模型价格**只填写单价和计费单位。输入、输出及适用的数量参考值自动带入并只读展示。已经保存的单价和历史价格版本各自保留。
- **同上游映射**用独立弹窗展示当前上游的映射及启用状态。确认后回到原位置，可继续配置另一个模型，最后一次提交。
- **Responses**可直接在「参数与转发」声明支持的原生协议并预览请求路径。OAuth 继续按账号绑定的协议转发。Responses 最小诊断请求使用合法的输出预算。
- **长列表阅读**在四处游标列表增加向下连续加载、返回最新位置和重试控制。见[列表交互记录](../maintenance/infinite-scroll-20261114/README.md)。

## 实测与升级

功能源码已先在 237 核验。从 schema 47 升至 50 后，已实测规格入库、覆盖保存、客户端读取、定价只读带入、Responses 保存，以及连续配置两组映射。机房 DSH 使用当前默认 `Codex-gpt-6.2-sol`、`medium` 经原生 Responses 完成工具往返和最终回复。已有生产配置经前后指纹核对一致。具体型号与证据范围见[237 实测收据](../acceptance/2026-11-18-model-specifications-deploy237/README.md)和[模型兼容核实清单](../provider-verification-checklist.md)。

可按[部署说明](../deployment.md)使用发行包升级。历史生产实测对应各自记录的制品提交。正式发行状态和公开产物核对见[发行收据](../acceptance/2026-11-18-qiwolf34-release/README.md)。

# v0.34.0-qiwolf.32 — 用量账务、价格管理与当前配置选源

状态：发行准备中。当前公开正式版仍为 qiwolf.31；本版尚未完成 exact main CI、发行流程和公开产物验收。下列功能已有分阶段源码与指定生产部署证据，不能据此宣称本次发行包已验证。Cargo 保持 0.34.0，数据库由 qiwolf.31 的 schema45 升至 schema47。

## 本版范围

- 用量看板增加区间总计、模型调用分析、时间与实际来源筛选；完整纳入历史 USD 与 CNY 调用，展示统一换算人民币，原币种和账本金额保留。Token、Search/Fetch 按次与已接入的 ASR 时长计价分开；TTS、图像、视频等可配置价格不表示已接入对应生成接口自动结算。
- 明细分页与完整统计独立读取，翻页和每页条数变化不重算图表，首次、筛选变化和刷新读取完整报告。独立只读快照避免全历史图表占用分页和写账的主连接；旧筛选的慢响应不覆盖新筛选，加载或失败不显示冒充当前范围的旧图。三类 analytics API 与原列表保持相同管理、门户归属或当前 Key 权限，完整统计不被分页截断；大范围分析仍可能耗时，不以轻分页耗时冒充图表性能。
- 管理统计在单次扫描内复用连续相同分组的位置，减少重复查找；原 SQL 字段、全部请求与尝试、NULL、排序及溢出语义保留。该状态不跨请求，不影响模型路由或配置生效。
- Token、数量/时长与按次价格均可修改、停用/恢复和删除归档。修改创建不可变新版本；停用最新版本不回退旧价格，删除仅软归档，历史仍可查询，已预占尝试继续按旧快照结算。表单按实际模型用途选择计价，ASR 用途优先于兼容的 Chat 执行类型。
- 来源与价格表单可读取同一实际来源 Key 的模型目录，自动填入供应方声明的输入/输出界限并显示出处和时间；管理员可调整。手工来源配置与现役 OAuth 约束优先，缓存按来源身份隔离，Key/映射变化使旧值失效，未知不猜值。目录声明不是付费推理或硬窗口实测，发现不改费率或已有管理员配置。
- 取消所有本地金额预算门限、现金预占占用和超估算冻结，包括有限额及历史冻结账户。已知实费完整记录，不封顶于估算；未知金额为 null。旧在途 hold 按原 allocation 释放，历史终态账本不重写。预算修改 API 返回 410 budget_enforcement_disabled，历史统计可读。
- 每次调用按当前目标顺序、Key 策略和可用状态选源，不再被会话 ID、旧来源 pin、历史 active 或 credential affinity 固定。配置改序、停用与更换 Key 对下一调用生效；忙源先试其他可用候选，400/429 遵守当前切换开关，已提交输出的流不重放。
- 价格参考值不再充当输入/输出或数量准入门槛。真实来源窗口、参数合同、授权、RPM/TPM、并发及到期仍生效；仅启用 TPM 时检查排队后估算是否突破已入场令牌预占。无 TPM 且来源/价格未知的原生历史或音频可按 JSON 估算转发，不因未知金额拒绝；供应商仍可能拒绝跨来源加密历史或参数。
- 纳入先前已上线的六文件来源参数与诊断补丁（提交 e0c2ea1）：调整容量不改变来源身份代次，实际协议/运行身份变化仍改变代次；新参数表单同时提交来源代次与原始协议 SHA256，服务端事务内校验，旧表单冲突返回 409，旧客户端仍只获得原代次兼容保护。已保存 Key 可直接进入所选来源的参数页，无需重存凭据或模型映射；修改只作用于所选来源及其全部模型。
- 空终态流增加有界结构诊断，仅记录白名单事件/输出项类型、终态及输出 token 数，不记录正文、工具参数、加密推理、响应 ID、请求头或凭据。诊断不改正文透传与费用规则。六补丁已有部署/定向覆盖与本次文案修订后的 exact 源码测试分开，见[运行补丁审计](../maintenance/qiwolf32-release-20261114/runtime-patch-audit.md)。
- 手机价格列表完整显示长名称、参考值、状态和操作；滚动后打开菜单仍留在视口内。已有服务端逻辑与桌面布局保留。

## 升级与兼容

升级前完整备份数据库、主密钥、Web、程序、服务配置及 billing-outbox/dead-letter；schema46 增加时间汇总索引，schema47 增加币种及数量单位计价结构，旧数值标为 USD 保留原值，新数据默认 CNY。不能假设 schema45 旧程序可以直接读取/正确解释 schema47。迁移步骤见[部署升级说明](../deployment.md#schema47升级与回退)。回滚需匹配备份并考虑其后的新业务写入。安装不会自动改用户路由顺序、真实价格、Key、来源参数或供应商额度。旧金额 limit/frozen 字段只作历史元数据，不再作为调用门槛；自动探测不会把旧价格或管理员手填值静默覆盖。

旧文档中金额预算预占、未知费用扣估算、超估算冻结及会话锁源描述是历史合同，已被本版替代；历史当时的验收事实保持。具体当前行为见[身份与计量](../identity-metering.md)、[协议](../protocols.md)和[Key 池](../provider-key-pools.md)。

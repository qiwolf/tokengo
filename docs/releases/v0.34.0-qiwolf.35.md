# v0.34.0-qiwolf.35 — 用量模型分布与 API Key 模型候选

程序版本为 `0.34.0-qiwolf.35`，数据库 schema 为 50。

- **用量账本**根据双栏中趋势图与模型列表的实际高度计算默认预览。右侧超长时只显示能放下的完整行和展开按钮，短列表可直接看全。展开后可收起，切换查询区间后恢复默认行为。
- **API Key 模型授权**在管理员新建和编辑 Key 时，候选取当前可见模型与所属用户已保存授权的交集。授权设置保存后更新候选。用户没有模型授权时，列表没有可勾选项。已有但超出当前候选范围的显式授权可在折叠区查看和撤销。

## 验收与升级

用量折叠在 237 的 11 月 19 日真实账目中验收。1440px 视口下默认显示 4 项，其余 5 项可展开，图表说明到卡片底边由 280px 缩至 17px。[237 用量折叠收据](../acceptance/2026-11-19-usage-model-collapse-deploy237/README.md)

Key 候选筛选已通过 build-test 前端单测、WASM 构建和 Chromium 合成账户回归。237 使用现有用户真实授权只读验收，候选从 31 个缩到已授权的 18 个。[237 Key 候选收据](../acceptance/2026-11-20-key-user-model-scope-deploy237/README.md) 正式发行和公开制品状态见[发行收据](../acceptance/2026-11-20-qiwolf35-release/README.md)。安装与升级见[部署说明](../deployment.md)和[容器部署说明](../container-deployment.md)。

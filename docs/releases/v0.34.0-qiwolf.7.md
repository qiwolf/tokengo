# v0.34.0-qiwolf.7 · 容器交付配置修复

修复将发布附件导入 1Panel 或独立目录时的镜像引用问题。此前发布包复制了源码 Compose：不提供 `.env` 时，`image: ${TOKENGO_IMAGE:-tokengo:local}` 会引用未提供的本地构建标签；离线镜像保存的标签也与该默认值不一致。GHCR 本身已有版本、提交和 latest 标签。

- 发布时生成明确的 `image: ghcr.io/qiwolf/tokengo:sha-<完整提交>`，移除源码构建专用的 `build`；只导入 Compose 也能确定镜像。
- 离线镜像同时保存本地 SHA 标签及 Compose 使用的 GHCR SHA 标签，`docker load` 后可以直接使用配套配置。
- 发布 `.env` 示例保留绑定地址与端口，不再提供不起作用的镜像覆盖变量；更换版本直接编辑 `image:` 行。
- 源码仓库的 Compose 继续支持本地构建。本次不修改 Rust 业务实现、schema39、透传授权或计费合同，不自动更改现有部署配置。

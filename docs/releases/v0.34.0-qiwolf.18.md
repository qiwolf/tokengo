# v0.34.0-qiwolf.18

本版将“新建渠道”接到完整的模型家族与认证流程，并补齐可发起的公开客户端 OAuth、供应方参数合同和分层代理。Cargo **0.34.0** 不变；数据库由上个公开版的 schema **40** 升至 **41**。

发行状态：已公开发布。精确发行源码[`1b672c8d34cab98003ad4e6b45d9de4a4bee0e45`](https://github.com/qiwolf/tokengo/commit/1b672c8d34cab98003ad4e6b45d9de4a4bee0e45)的[精确main CI](https://github.com/qiwolf/tokengo/actions/runs/40181428585)和[发布流程](https://github.com/qiwolf/tokengo/actions/runs/40182556647)成功；9个公开资产和不可变GHCR镜像已独立验收，详见[发行收据](../acceptance/2026-10-25-qiwolf18-release/README.md)。

## 主要变化

- **完整新建入口**：“新建渠道”直接进入两行家族 Logo 卡片与居中的“更多模型”，再选 API 或订阅 OAuth、保存凭据、选择模型、检查参数与转发。保存前取消不创建空渠道；提交结果不确定时保留已存渠道并阻止重复提交，不以删除渠道补偿可能已成功的凭据写入。
- **API 与订阅分线**：模型家族用于组织接入；执行能力仍由真实来源、认证线路、原生协议、模型目录与明确配置决定。客户端接入协议指用户调用 TokenGo 的协议，供应方接口协议指 TokenGo 调用上游的协议；仅展示原生及允许的可表达转换。
- **可发起的 OAuth**：Kimi Code、MiniMax 中国/Global 和 GitHub Copilot 默认内置有出处的公开客户端标识，不再要求每个部署自行注册。设备码与令牌密文保存；轮询间隔、取消、过期、刷新租约和凭据版本保护保留。Copilot 授权页显示注册应用 OpenCode，目前仅开放账号目录明确支持 Chat 的模型，并按最终请求区分用户/工具续接及视觉标记。
- **真实目录与权益分开**：Kimi/Copilot 读取绑定账号目录；MiniMax 读取各地区官方公共型号快照，标记为 `provider_public`，不把公共型号宣称为账号订阅权益。真实登录成功也不等于所有模型可调用。
- **参数合同**：按供应方、认证、协议与模型匹配 reasoning/thinking、结构化输出、输出 cap、预算及相关参数。无法等价表达、能力冲突或越界的显式字段明确拒绝，不以静默删参或缩小 cap 达成成功。`none` 与省略分开；沿用可分发的官方来源兼容规则，并保留真实目录、人工确认与客户端显式参数优先级。
- **分层代理**：具体模型接入 → 渠道 → 家族默认 → 系统网络；支持继承、明确直连和 HTTP/HTTPS 代理。认证信息加密、保存有版本冲突保护。新建渠道尚未保存时，OAuth 按实际认证来源选择网络家族，Copilot 使用“其他 / 多家族”；不把当前选中的模型家族误当成首次授权出口。

配置详情见[账号授权来源](../oauth-providers.md)、[模型家族与参数合同](../references/provider-parameter-contracts.md)、[网络与代理](../outbound-proxy.md)及[推理关闭兼容](../reasoning-compatibility.md)。

## 旧参数配置注意

旧 `drop_fields` 配置不再删除客户端明确指定的推理、输出上限等受保护控制参数；这类冲突在出站前报错。普通供应方扩展字段仍可按渠道/模型的明确配置移除，并记录适配说明。上游报告较小输出上限时，只允许收窄客户端未指定的默认值；客户端显式上限会保留或明确拒绝，不再自动缩小并重试。已知上限在默认值生成后应用，并在出站及账务预留前重算边界，避免后续省略上限的请求反复触发相同上游限制。

## 新安装、升级与数据库

schema41 新增 `oauth_device_pending` 及过期索引，保存短期加密设备授权和轮询租约。迁移 SQL 与顺序执行路径随源码及产物分发，新安装和从 schema40 升级均运行同一迁移；不要复制生产数据库来获取此能力。

参数适配、公开客户端默认值和推理关闭规则来自源码，安装镜像或二进制即可得到相同规则。不会带入现有实例的账号、Key、Cookie、令牌、路由、价格、代理密码或人工能力配置；新用户仍需完成自己的认证、模型选择和经核实的输入/输出边界配置。未知兼容服务不会仅因名称相似而获得 `none` 或其他能力声明。

已先行验证的私有实例 `e281c51` 切换为 schema41→41，60张表、SQL对象、迁移历史、原有业务数据和保护配置保持不变。该现场结果与本次公开资产验收分别记录。升级前停服冷备状态目录、配置和服务单元；入口恢复后若已有新写入，不可直接倒回冷备覆盖新业务。

## 已完成验证与待验收

实现基线在 build-test 上完成 server lib **469**、Web **145**、关键集成 **73** 项测试，合计 **687** 项；Linux server/CLI 和最终 WASM 构建通过。隔离数据库中从首页新建入口实际保存合成渠道、凭据和模型并到达参数页，保存前取消未新增渠道。该数量是定向覆盖，不能代替最终公开发行提交的完整工作区和资产检查。

同一新服务端经 TokenGo 管理 API 对四个真实官方设备端点完成发起、按间隔轮询到 `pending`、取消和密文清除检查。**没有登录真实用户、取得真实用户令牌或执行真实上游模型推理**；账号确认后的刷新、订阅权益、模型可用性及真实用量/账务仍需逐账号验收。代理配置与选择规则已有测试和 UI 读回，不能由此泛称所有代理服务器、认证代理及所有网络环境都已实测。

Qwen/iFlow 的旧 OAuth 已由官方停用；Gemini CLI、Claude Code 的官方认证使用范围不等于本第三方网关授权。Antigravity 未确认完整适用合同。未开放来源保留明确原因，不用“待配置”冒充可接通功能。Gemini 原生 `generateContent`、SOCKS 及所有供应方/客户端的无条件兼容不在本版承诺内。

## English

Connects the New Channel button to the complete family-logo, authentication, model and parameter flow. Adds published public-client device OAuth defaults for Kimi, MiniMax CN/Global and Copilot, provider/authentication-aware parameter matching, and source/provider/family HTTP(S) proxy policies. Copilot is limited to models whose account catalog explicitly supports Chat; MiniMax public catalog metadata is not account entitlement. Cargo 0.34.0, schema41, Linux AMD64 distribution.

The implementation baseline passed 469 server library, 145 Web and 73 targeted integration tests on build-test. Four real device flows were started, polled pending and canceled through TokenGo; no real-user login, token refresh or upstream inference acceptance is claimed. Published as [v0.34.0-qiwolf.18](https://github.com/qiwolf/tokengo/releases/tag/v0.34.0-qiwolf.18); exact-source CI and independent public artifact verification passed. The final build-test workspace recorded 1345 passed, 0 failed and 3 ignored Rust tests; targeted historical tests are not added to this total.

# v0.34.0-qiwolf.4

本次汇总 qiwolf.3 之后的控制台、用户/渠道生命周期和自定义探针改造。Cargo 仍为上游 0.34.0；下载附件、镜像标签和构建提交以本 Release 实际产物为准。

## 主要变化

- 用户设置按任务分区，新增/编辑使用弹窗；统一按钮轮廓、操作列、输入框和紧凑模型卡片。路由、回退及协议参数改为页面点选，减少无关展开表单和 JSON 编辑。
- “管理上游 Key”先显示现有凭据，“编辑 Key”与“选择模型”分开。原 API Key 可由管理员显式查看或复制，替换留空保留原值。点击模型输入框读取所选 Key 目录，支持搜索、多选和手工输入；上游模型名在前，可选本地映射名在后，原映射身份保持。
- 用户支持删除归档：撤销 Key 和登录，保留用户身份、请求及财务历史。普通用户只能恢复自己暂停的 Key，不能绕过管理员停用或撤销。
- 渠道删除在事务中清理所属 Key、模型映射及可变授权/路由引用，保留原历史账本和价格证据；最后一项显式授权移除后仍为空集合拒绝全部，空虚拟链或空时段停用。运行请求或未结算项存在时拒绝删除。
- 新授权候选只显示可见模型；已有兼容隐藏/目录外授权单独折叠保留，只能撤销，取消不提交；保存其他字段不丢失旧授权。目录失败不会回退为允许全部模型。
- 新增管理员自定义探针：表单新增/编辑/保存/取消、启停、手动/定时执行和删除，支持状态、内容、延迟或向量维度断言，带配置版本冲突、总超时、响应上限及租约保护。
- 探针支持普通 Chat / Responses / Messages / Embeddings、已绑定 OpenAI OAuth Responses，以及明确声明的独立 Search / Fetch。OAuth 使用正常认证刷新与有界 SSE 收集，修复响应 MIME 与实际 SSE 不一致；工具使用专用请求结构与请求单位。
- 所有自定义探针记录为系统诊断，不借用普通用户或 VKey、不扣用户额度；记录实际 Token 或请求次数、认证与价格快照，缺价和订阅 USD 成本保持未知。来源/Key 并发门及工具 QPS 与业务调用共享，取消/重启沿用持久结算恢复。

## 两种部署方式

同时提供 Linux AMD64 直接部署包和容器；离线镜像包继续保留。标签发布流程另向 `ghcr.io/qiwolf/tokengo` 推送版本、提交及 `latest` 标签。请选择本 Release 已实际生成的附件或镜像，并核对校验摘要；未声明其他 CPU 架构已构建。

服务端与 Web 从同一发布提交构建。运行时业务代码基线为 `febb2c91ff51516716a4a40c502d7b41316796f9`，已完成测试部署验收；后续发布文档和包装变更不自动扩大业务验收范围。容器和原生路径见 [部署指南](https://github.com/qiwolf/tokengo/blob/v0.34.0-qiwolf.4/docs/deployment.md)与[容器指南](https://github.com/qiwolf/tokengo/blob/v0.34.0-qiwolf.4/docs/container-deployment.md)。

## 验证与升级边界

业务基线本地前端105项、服务端库及两类集成共305项通过，后续来源迁移、OAuth MIME/gzip/SSE与工具类型定向回归通过。测试部署完成有限真实 OAuth Responses、独立搜索和提取；首次 OAuth 解析失败保留原账本，修复后独立重验成功。新增/编辑/保存/取消/启停、授权隔离及桌面/390px布局另有页面检查；三类临时探针删除通过 API 读回核对。本轮没有重跑960次真实并发压力，也不宣称所有模型/订阅/客户端均兼容。

升级前成套备份数据库、主密钥、程序、Web 和服务配置。WAL 数据库须使用 SQLite backup API 或干净停服备份；不能只复制正在写入的 `.db`。测试升级保持 schema37、53表和旧历史，安装包不会按 IP 自动合并其他部署的本地渠道。不要用旧数据库快照覆盖用户升级后的新写入。

月度套餐、原始 Token 额度、多实例共享配额、可配置独立系统诊断总预算和全部供应商发票对账仍未实现。OAuth 订阅探针不支持普通输出 Token 参数，以超时与响应大小约束；成本未知不等于免费。完整合同见 [自定义探针](https://github.com/qiwolf/tokengo/blob/v0.34.0-qiwolf.4/docs/custom-probes.md)、[需求覆盖](https://github.com/qiwolf/tokengo/blob/v0.34.0-qiwolf.4/docs/requirements-status.md)及[验收状态](https://github.com/qiwolf/tokengo/blob/v0.34.0-qiwolf.4/docs/acceptance-status.md)。

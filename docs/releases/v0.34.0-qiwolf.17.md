# v0.34.0-qiwolf.17

本版补齐新安装和升级时的推理关闭能力，并包含移动端模型分类和筛选布局改进。Cargo **0.34.0**、数据库 schema **40** 不变，无数据库迁移。

发行状态：候选，等待精确提交CI、发布和公开产物独立验收。见[发行记录](../acceptance/2026-10-25-qiwolf17-release/README.md)。

## 主要变化

- 有效同来源目录上，官方OpenAI Luna及DeepSeek补齐目录未列的`none`；新安装和读取旧缓存采用同一规则，不依赖私有数据库SQL。原始缓存不改写，界面区分上游声明与内置兼容。
- DeepSeek原生`effort.supported_levels/default_level`字段得到识别，矛盾/无效声明保持未知；官方端点规则不套用第三方兼容API。
- DeepSeek Responses保留`reasoning.effort=none`；Chat/Messages将none转换成`thinking.type=disabled`，不发送无效effort值。明确冲突拒绝，管理员默认与客户端显式thinking的优先级保留；Responses/Messages跨协议转换到已知DeepSeek来源时保留关闭意图。
- 手工档位列表可排除none，默认档位不会自动切成none。其他模型和第三方来源依据实际声明与人工确认，不按名称猜。
- 移动端模型分类在352px起同排、更窄等宽换行；筛选分组和排序控件压缩布局，保持原筛选/排序逻辑与触控尺寸。

## 验证与配置边界

新建OAuth渠道仍需核实完整的输入/输出上界；刷新目录不猜上界，不复制现有实例的账号、密钥、路由、价格或策略。[推理关闭兼容](../reasoning-compatibility.md)说明各协议实际字段与升级边界。

历史现场SQL记录经文件审计，除本版推理关闭规则外，已定位项目属于实例配置、业务迁移/清理或测试夹具，相关通用配置路径已存在。此结论不是全部历史生产数据库的穷尽差异证明。没有把私有账号实测扩大为所有供应商/账号验证。

## English

Adds portable, provider-aware reasoning disable support for official OpenAI Luna and DeepSeek, including existing valid catalogs without importing private database settings. DeepSeek effort metadata is parsed explicitly; `none` becomes native `thinking.type=disabled` for Chat/Messages while Responses keeps its native control. Manual lists, defaults, explicit client controls and source identity checks remain authoritative. Unknown third-party APIs receive no inferred capability. Includes compact mobile model categories and filters. Cargo 0.34.0 / schema 40; Linux AMD64 distribution. This is a release candidate until exact-commit CI and publication receipts are available.

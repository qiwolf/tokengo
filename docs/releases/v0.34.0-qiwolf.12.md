# v0.34.0-qiwolf.12

**已[正式发布](https://github.com/qiwolf/tokengo/releases/tag/v0.34.0-qiwolf.12)并通过公开产物独立验收。** 本版汇集qiwolf.11之后的按名路由性能修复、旧虚拟模型名称兼容、SiliconFlow BGE-M3原生维度适配及管理界面布局改动。发行源码 `6bf36fa917cd87209286c88a805ddc2cb6e52669`，Cargo **0.34.0**、schema **40**。发布时间2026-10-23 18:25:37 UTC（北京时间10月24日02:25:37）。

## 按名路由与兼容续验

`1d5d089`、`6e03657`、`0d0e6e7` 将运行时的完整目录展开改为先按名称/ID定位，再加载命中的模型、来源和虚拟策略。列表和按名查询共用路由构建逻辑，类型、上下文依据、排序、来源故障及停用语义保持一致。目录路由读取只取所需kind/context元数据，不为一次推理展开无关模型的reasoning等管理信息。私有与共享策略、兼容核验及续验使用同一路径，避免每个目标重复展开完整目录。

这覆盖Unknown、Chat、Embeddings、Rerank、Image、Video、Audio七类 **ModelKind元数据查询**，不新增图片/视频/音频转发端点。现有共享别名HTTP转发合同覆盖Chat、Embeddings、Rerank；不要从七类元数据一致性推定七类真实业务调用均已验收。

旧导入名称的索引可能不符合当前Rust归一规则，因此保留仅ID/名称元数据的兼容扫描、首个未回收记录优先级与重复名安全失败语义。无关坏JSON不应污染合法查找，命中记录损坏仍应拒绝。此实现仍扫描部分映射名、kind及相关目录元数据，**不是O(1)查询或授权缓存**。当前用户/Key、入口授权、来源状态、版本和时段仍在实际发送前重读，排队后撤权继续生效。

现场当前运行的是此前部署的私有性能补丁；本版发布不等于生产已升级到新正式产物。最终版本的性能数值、构建测试和公开产物验收须以本轮精确发行源码收据为准，不从代码结构推算提升比例。

## BGE-M3 原生维度适配

`cfd7e35` 在最终上游传输边界，仅为精确 `https://api.siliconflow.cn/v1`（可带末尾斜线）的 embeddings 请求、模型 `BAAI/bge-m3` 且显式 `dimensions:1024` 时移除该冗余参数：该来源原生返回1024维，却拒绝此可选字段。输入、编码格式和其他参数保留，不截断或投影输出。

其他来源、路径、模型名及不同维数保持原请求，由上游按自身能力处理；不将该适配泛化成允许任意维度。虚拟模型身份、维度和输出完整性校验仍生效。GPU官方分词器、8192窗口等仍是独立现场配置，不由本版网关容器自动修改。

## 管理界面布局

本版同时收录已有七个前端文件的布局改动，不改变对应API授权或密钥操作语义：

- Key列表的显示、编辑、启停和删除按钮统一分组并允许换行；用户模型授权复选项垂直对齐。
- 服务商模型表按七列分配宽度，按钮保持可读并允许换行；模型映射行对齐输入、复选框和按钮。
- 上游Key优先级配置与底部取消/保存操作分组，错误提示保持在操作区前；推理设置说明和更新模型信息按钮分组留出间距。
- 虚拟调用策略各步骤使用独立边框与间距；透传服务表单、分栏与记录间距统一，小屏改为单列，所需样式不再依赖探针页面的懒加载样式。

七个布局文件与此前build-test Chromium156验收清单逐字节一致，19项布局断言涵盖桌面及390～1024px断点；本轮另修正虚拟模型帮助文案，明确按真实后端能力接收，不再暗示小范围限制。本轮发行源码另经Web125项检查及WASM构建通过；历史19项视觉断言与本次构建证据分别保留。

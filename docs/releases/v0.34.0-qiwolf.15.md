# v0.34.0-qiwolf.15

本版统一控制台与关键操作弹窗的视觉样式，改善密集配置、长内容和窄屏操作。Cargo 版本仍为 **0.34.0**，schema **40**；没有新增数据库迁移，不改变业务接口、权限或既有配置的保存与删除规则。

本版已公开发行，精确提交`c3ecd31250f061f781970b45217cf31743f41e7d`。本地合并测试与公开发布流程已完成，完整记录见[发行收据](../acceptance/2026-10-25-qiwolf15-release/README.md)。

## 控制台布局

统一字号、按钮和表单尺寸，收紧页面标题与说明的层级，调整表格、状态标签和留白。供应商操作在中等宽度下形成独立操作行，避免按钮错位；长名称按可用宽度显示，操作按钮保持成组。探针说明、工具栏、列表和空状态分别留出空间。

系统设置分为接入与密钥、请求参数、运维凭据、账号安全、维护与日志五组。桌面使用左侧分组导航，窄屏改为横向切换；当前分组单独展示，切换保留未提交的输入。

## 关键操作弹窗

用户编辑、Key 管理和模型映射使用一致的标题、内容与操作区域。用户和 Key 的已使用金额、在途预占采用同字号的紧凑标签，与相邻输入控件对齐。

Key 显示弹窗预留加载、复制成功和失败反馈区域，反馈不改变窗体尺寸。长内容在内容区滚动，底部操作保持可见；新建密钥及简单弹窗表单增加字段、说明与按钮间距。模型映射末行操作滚动到底后不被固定底栏挡住。

价格入口使用“配置价格”“调整价格”“沿用此版本”等明确动作。配置或调整继续通过创建新版本生效，历史价格与账目快照保留；本次没有增加覆盖或删除历史价格的行为。

## 输入与状态一致性

为未显式声明 type 的文本框补齐统一的边框、字体、圆角、宽度和盒模型。输入框、下拉框及可编辑文本域使用一致的聚焦反馈；错误状态保留红边及对应聚焦环，避免被普通样式覆盖。明暗主题与窄屏触控尺寸均纳入验证。

## 升级与回滚

公开交付仍包括Linux x86_64原生包和linux/amd64容器，安装方式见[原生部署](../deployment.md)和[容器部署](../container-deployment.md)。服务端与Web应使用同一发行提交构建的配套产物，不混用不同版本的静态资源。

升级前按既有部署流程保存数据库、原主密钥、运行配置和旧程序/镜像。schema40保持不变不等于可以忽略升级后的业务写入：完整程序回滚按既有版本的配套备份规则执行。本版前端修订自身不要求修改用户、Key、预算或价格数据；更新页面后重新加载浏览器以应用新的带哈希资源。

标签及下载包内的文档是构建时快照；发布后补充的验收收据维护在main和Release页面，不移动既有tag，也不声称先前下载包已经包含后补文档。

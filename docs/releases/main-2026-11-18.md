# 2026-11-18 main 更新：模型规格、渠道映射与 Responses

本次将五项源码提交纳入 `main`。237 使用 `a6e3e856e7d2739609b6bb22c08ff9b2fd1e11ba` 的服务端和前端，2026-11-18 完成切换和实测。公开正式版仍为 [v0.34.0-qiwolf.33](v0.34.0-qiwolf.33.md)。

| 变化 | 管理员和客户端可用的功能 |
| --- | --- |
| 模型规格 | 预置 96 条官方型号规格、18 条显式别名和 19 条中转差异。添加渠道模型时按实际的上游名称带入已知字段，支持修改该渠道的同名模型。客户端可在 `GET /v1/models` 的 `specifications` 中读取其可用模型的规格。 |
| 模型价格 | 单独维护单价与计费单位。上下文窗口、最大输入和用量参考值在渠道模型里维护。定价表单只读带入参考值，已有手工值与每个价格版本的历史快照保留。 |
| 同上游映射 | 独立弹窗显示当前 Key 下该上游的全部映射及启用状态。确认后返回模型列表原位置，可连续配置多个上游，再统一保存。顶部重复的「返回 Key 列表」已移除。 |
| Responses 协议 | 在「参数与转发」可直接声明 API Key 或免认证来源的原生协议，并预览客户端路径与实际转发字段。绑定 OAuth 的来源仍按账号固定协议运行。Responses 最小诊断请求采用 16 个输出 Token。 |

基础规格优先使用官方数据。渠道变体仅登记已核对的差异。规格声明和费用估算参考值分别记录，目录中缺失的字段保留为空。详情见[模型规格维护说明](../maintenance/model-specifications-20261118/README.md)。

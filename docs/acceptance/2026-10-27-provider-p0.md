# 多厂商兼容第一批（P0）验收记录

## 已实现

百炼原生Responses依精确模型区分总生成与可见答案上限。仅答案或未知语义没有可信总上界时拒绝；未把Chat的thinking_budget当作Responses有效思考上界。列明模型的max_output_tokens最小16；不向任意未知型号泛化。最终默认值、合同校验与计量在副本完成，失败保留原请求，既有预占/结算调用位置不变。

原生Chat新增Gemini工具thought_signature和Ark助手encrypted_content归属识别。显式/匿名会话复用来源、鉴权、用户、模型、协议及代次保护；普通无opaque Chat不额外建立会话pin。JSON原值保持，SSE按choice/tool索引聚合，闭合后登记；完整message快照取代旧delta。其他原生协议出现这些Chat专属形态明确拒绝，不能借同值签名绕过。

新增版本化ContractEvidence/ProviderContractIdentity。全来源说明在顶层inventory输出，每模型只带有界描述；证据不是授权、运行验证或新执行器。规则元数据不改变配置及会话代次。Ark升级公告与旧指南的冲突仍未通过真实账号解决，不据此放开新能力。

## UI自定义推理强度方案（本次仅方案）

现有供应商→模型→接入设置已有“人工确认支持档位”及逗号分隔输入；后端按连接＋模型保存manual_levels，替换目录列表，客户端显式参数优先。来源或上游映射变化后旧设置失效，保留这项保护。

建议沿用此面板：

1. 分别展示“上游声明”“实测补充”“人工设置”及最终生效值。实测说明时间、连接、模型和协议；不能把兼容值标为上游声明。
2. 将输入改为档位标签，允许1–16个小写参数值，每项≤32字节；明确值是原生传参值。none解释为关闭推理，“沿用服务商默认”表示不补参数。
3. 保留当前“替换列表”语义并明确标注；未来增加“追加实测值”时单设字段，不能暗改manual_levels含义。人工排除优先于自动补充。
4. 默认档位选项实时跟随编辑后的列表，档位和默认一次原子保存；移除当前默认值时必须先改默认，避免保存后出现无效配置。
5. “恢复目录判断”清除人工覆盖；可选“验证此档位”明确会发起一次最小调用，记录结果及范围。验证成功先产生待应用证据，用户保存后生效，失败不自动改列表。
6. 更新上游目录不能抹除仍有效的人工声明或伪造实测；账号、地址、头、协议、上游映射变化后提示重新确认。

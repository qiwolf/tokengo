# 无状态记忆调用修复

> 已撤销的历史方案：五处AG/HS调用端已恢复原件，专用header及服务端分支均已移除。当前通用方案见[原生历史保留规则](../../native-history-retention.md)。以下仅记录当时的试验与验收，不可作为当前部署步骤。现场补丁原件仅保存在私有审计目录。


2026-10-26，Key93为多套记忆服务共用，其同源匿名池已达4096条。调用方虽然只使用返回文本，网关仍登记输出加密推理材料；新输出因容量拒绝，上游200变成网关503。

新增按请求声明的无状态模式，合同见[调用说明](../../stateless-memory-calls.md)。不按Key、User-Agent或store:false推断。默认普通会话保护保持；不扩大池、不删除历史、不轮换Key。持久化故障增加固定脱敏原因码。

历史上曾对五处记忆调用端试验专用头，随后全部恢复原件；补丁不随公开包分发。完整私有审计记录保留于本地review目录。

生产更新顺序：先服务端，确认新协议生效，再更新调用端。回滚顺序：先恢复调用端原件与现行服务，再切回旧TokenGo二进制。schema41不变，CLI/Web保持原版本来源，历史和Key不做维护性清理。切回旧服务端会恢复旧容量行为，因此不将回滚称为解决原问题。

验证与部署状态由本次任务交付收据记录，不能以本文计划视为已上线。

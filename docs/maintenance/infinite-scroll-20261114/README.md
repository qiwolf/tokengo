# 列表连续滚动与图标导航

2026-11-14，build-test验证通过，待Web切换。按用户要求移除列表底部翻页文字按钮，滚到尾部自动追加更早内容；右下角固定图标可回到最新，失败时原位置显示重试图标，两个图标均有可访问名称及48×48px触控区域。

## 适用范围

| 列表 | 新行为 |
| --- | --- |
| 普通用户运行总览：最近调用 | 每批12条，向下追加；读取历史时不以5秒快照替换已读列表，分类统计独立刷新 |
| 我的空间：调用明细 | 按所选时间范围连续追加，批量25/50/100可选；筛选、批量和刷新重置游标 |
| 管理员：用量账本 | 保留筛选条件，按游标追加；每批条数不再代表总列表上限 |
| 管理员：运维令牌 | 自动追加，创建/撤销对话框打开时暂停列表加载 |

其他配置表格目前一次性返回完整数据，已可自然向下浏览；编辑表单仍按其保存操作提交。管理员总览的最近12条快照和系统日志内存尾部没有历史游标，未伪造无限历史。本次没有新增后端分页接口、权限、路由、价格或额度规则。

## 加载合同

使用 IntersectionObserver 观察尾部，不使用高频scroll事件。每次最多一个列表请求，按ID去重；空页、游标不推进及服务端无下一页时停止。失败保留已读内容，并停止自动重试；管理员或用户可按重试图标继续。分页不重新运行整个时间范围统计，查询统计仍独立完成。离页取消页面异步任务并断开Observer，避免旧响应写入已销毁状态。

回到最新的图标固定在视口右下角，滚动后仍可用。门户及账本定位到各自列表头；手机适配安全区。保留状态文字与aria-live，不用颜色或图标独自表达加载失败。

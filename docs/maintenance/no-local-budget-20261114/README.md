## 最终行为

所有用户与Key取消本地金额预算准入、现金预占占用及超估算冻结；历史限额与冻结字段不再限制调用。价格的Token/数量上限只作估算参考，不因超过价表参考值拒绝请求。无价格保留未知费用，不因未知金额拦截。已知实际费用完整记录，不封顶在原估算；未知实际费用为null，不拿估算伪造实费。历史终态账本不重写，旧在途hold恢复按每个allocation原占用释放。账户权限、RPM/TPM、并发、到期及真实来源窗口/参数校验保留；TPM显式启用时的令牌计量仍独立执行。

PUT /api/budgets返回410 budget_enforcement_disabled；GET及usage返回budget_enforcement=false。用户/Key创建与更新兼容忽略旧limit_micro，不再继承、比较或写入金额门槛。界面改为只读消费汇总，移除预算与冻结操作；价格字段显示用量参考值，自动读取与管理员调整保留，明确不限制调用。

每次调用按当前模型配置顺序、Key priority/concurrent策略及实际可用状态选源。会话标识、旧protocol_sessions/artifact归属、历史active来源及credential affinity不再决定选源；不读写新会话来源绑定。配置改序、停用、Key更换对下一次调用生效，不要求新建会话。忙源先试剩余可用候选，全部忙才沿用现有有界等待。400/429故障切换严格服从当前开关，关闭时不会被其他错误分类绕过。原生历史按请求转发，供应方参数是否合法仍按真实协议合同校验；不承诺不同供应商接受彼此加密状态。

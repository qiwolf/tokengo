## 行为

来源参数页、Token价格创建/修改页会读取所选来源、相同凭据与模型的供应方目录，只采用明确正整数容量字段。显示目录地址、时间与声明状态；缺失字段保持未知，可手工填写，支持重新探测。管理员配置优先，异步旧响应不会覆盖新来源或用户输入。供应方声明不是最大窗口的压力验收。OAuth继续使用现有OAuth绑定能力，不借API Key目录推断。

探测结果按来源、逻辑模型、上游模型、凭据身份和绑定版本隔离缓存；来源在探测期间变化则409，缓存和审计原子保存。排队期间声明窗口变化不得超出已入场预占额度。有效缓存可补齐价格默认值及执行预占依据；价格不能反过来充当来源能力证据。明确输入的价格上限优先于自动默认值。重探测不会静默重写旧价格；旧价格通过修改创建新版本，金额、历史账单保留。

价格管理同时交付Token、单位和按次三类的修改、启停、删除归档，详见相邻price-lifecycle报告。

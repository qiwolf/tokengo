# 人民币、单位计价与模型优先的价格配置

用户确认：新价格、额度和结算使用人民币；历史美元账目保留原币种，不使用汇率换算。用户同时明确当前不存在需要迁移美元限额的用户，不增加额度过渡拦截。本次延续已选的 `refactoring-ui`，将价格配置改为先选模型、再选当前有效来源渠道。

## 币种与历史

数据库迁移 v47 为既有 token／按次价格、账本、预算补记 USD，金额数值不变；既有价格快照缺少币种时仍按 USD 解析。原美元预占、重复预占及重启后的结算使用美元预算，不能被新人民币规则改写。新价格只接受 CNY，预算按用户／Key及币种分别记账。已存在的冻结状态继续生效；美元预算只允许保留限额并显式调整冻结状态，不创建新的美元价格或美元预占。

用量、模型趋势、普通用户门户和账本按 CNY／USD 分别查询，默认 CNY，不能把两个币种直接相加。账目明细明确返回币种及实际计量数量。旧价格仍可在历史版本中查看；沿用美元版本时清空金额，要求重新填写人民币价格，避免1:1改符号。旧模型若未创建新的人民币价格，Chat／向量调用沿用现有“未定价”处理，不猜测人民币单价；要求显式按次价格的原生Search／Fetch须先配置CNY版本；旧美元透传价格也不会成为新的美元扣款。

## 价格配置

模型目录来自当前有效渠道与已启用模型映射，并排除全局停用模型、停用供应方、无效凭据和历史接入。以规范化模型名和具体来源渠道去重。同一模型的不同实际渠道保留独立价格，避免把不同来源强行合并。选择来源后显示供应方、渠道名、上游模型名及 API 地址，不再要求先在大量 Key／地址组合中找模型。

价格版本不可变：Token按输入／输出每百万Token；已有Search／Fetch／透传按次；单位价格支持音频秒／分钟／小时、字符、UTF-8字节、图片张数、视频段数。单位改变也会替换同一模型／渠道／币种的当前版本，而不是把分钟与小时同时标为当前。

金额统一采用整数微元（1元=1,000,000微元），结算使用整数运算向上取整，不通过浮点金额累计。音频数量统一记录毫秒；字符／字节／张／段使用千分量单位。音频价格无论按秒、分钟或小时填写，最大预占时长都以秒输入并精确到毫秒。

字符、字节、图片、视频已具备通用价格配置和核心预占／结算能力；对应生成接口尚未接入自动计量，编辑器已明确提示。不能把价格选项存在当成这些业务接口已经可用。

## ASR 实际计量

新增原生 `/v1/audio/transcriptions`，复用有效模型映射、API Key权限、渠道／凭据并发及出站配置。WAV、MP3直接核验媒体时长，其他格式可选使用ffprobe（仅允许pipe协议、10秒超时、退出清理）。不采信客户端自报duration，不使用网络请求耗时或返回token数当音频时长。成功响应有明确时长字段时优先记录上游报告，否则使用媒体测量；来源、输入时长、上游时长和最终计量数进入账目追溯信息。

请求前按配置的最大时长预占，避免上游报告略高于容器测量时发生少扣和误冻结；完成后按实际计量结算。超过配置上限的输入在发出前拒绝。实际报告超出预占的处理继续沿用原有超支保护。未知数量保持未知，按现有预占估算规则处理，不能显示成已知零或供应商确认费用。

结算意图写入durable writer并fsync，重启后按原币种、价格快照和计量数量重放；重复结算不能重复扣款。未发送释放预占，已发送但取消／未知用量与明确零用量分别记录。

硅基流动的[ASR接口文档](https://docs.siliconflow.cn/docs/api/audio-transcriptions-post)保证转写text字段，并未保证每次返回音频duration，因此不能只依赖返回体。其[TTS说明](https://docs.siliconflow.cn/docs/userguide/capabilities/text-to-speech)说明计量可按UTF-8字节，不能把所有语音模型统一当作字符或Token收费。本次没有调用生产硅基流动接口，也未自动导入或猜测其价格；测试中的价格是合成示例。

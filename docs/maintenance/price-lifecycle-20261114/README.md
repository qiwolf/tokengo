## 行为

模型价格支持明确的“修改”“停用/启用”“删除”。修改固定原模型、来源与币种，创建新价格版本；已被替换版本拒绝覆盖，避免旧页面覆盖新设置。停用或删除最新版本不会回退旧价格；删除为归档，可在“已删除”范围查看。历史价格行及账本快照不修改，已有预占仍可按原快照幂等恢复和结算。有限预算/必须定价策略保留；未定价金额仍为null，不把停用解释为免费。

Token、时长/数量、按次三类均支持管理。普通Key不能调用管理员管理接口。状态与审计同事务写入，不迁移schema。界面当前配置范围保留停用项，删除有原生dialog确认，错误在操作位置显示，模型/来源在修改时固定。

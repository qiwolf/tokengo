# 新模型的目录用途维护

2026-10-27。修复新模型显示“还没定”，但管理页面没有用途维护入口的问题。

在“供应商与接入 → 管理模型 → 用途”点击“配置用途”，或在“模型与路由 → 详情与统计”中维护“目录用途”。可选择对话与推理、文本嵌入、重排、图像、视频、音频、工具；选择“跟随已识别用途”会清除人工目录分类。

展示名称与用途共用已有 `/api/model-presentation` 接口，两处编辑器保存和读回一致。退出编辑而不保存不会写入。保存时保留已有显示名；API调用名不变。目录分类只决定管理目录分组，不会修改实际执行类型、路由范围、协议、权限或推理档位，不按模型名字添加白名单。

首次添加的模型可以尚未发生实际调用、没有执行类型识别；这时仍应允许管理员将它归入适当的目录。本轮用未知执行类型的Terra验证归入对话分类及清空回退，真实执行类型保持未知。

验证：build-test的154项Web单元检查、2项用途HTTP回归通过，WASM正式构建成功；真实HTTPS管理员页面8项检查通过，包括保存、重新打开读回、两处入口一致、取消未保存修改和整页刷新。现场Terra目录用途已设为对话与推理，模型对话分类中可见。

本轮只更新Web资源，不重启或替换服务端，无数据库迁移，schema42不变。未进行Terra真实推理请求；目录可见不等于模型能力或上游推理已验收。回滚可恢复此前Web目录；已保存的目录用途可通过现有接口保留或清空，不用旧数据库覆盖新写入。

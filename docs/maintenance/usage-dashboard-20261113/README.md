# 用量看板、模型调用分析与筛选栏

本次承接 `b097bf6` 的时间范围查询。用户要求补齐真正的区间看板，参考其提供的模型分析截图；明确选择 `refactoring-ui` 后实现。管理员与普通用户共用看板组件，接口继续按原有权限归属查询。

## 页面行为

- 区间指标：去重请求总数、尝试次数、已知扣款、总输入/输出 tokens、平均 RPM/TPM；未知用量不冒充已知零。平均速率按区间开始至结束（未来部分截至当前时间）的实际经过时长计算。
- 用量趋势：按区间长度自动选择固定时间间隔，空时段补零；支持 tokens、调用次数、扣款切换，鼠标、键盘或时间段选择器可查看每个区间的具体用量。区间包含开始、不含结束。
- 模型调用分析：调用趋势、调用次数分布、调用次数排行三个视图，统一使用实际调用尝试数；重试分别统计，顶部的去重请求数另列。排行保留前八个模型及“其他模型”，不丢弃其余模型的合计。
- 筛选栏：常用条件在桌面按一行内联排列，窄屏允许换行；自定义时间可展开额外日期行。上游接入、对象状态收进“更多筛选”。选择用户后只列出其 API Key，并清除原先属于其他用户的 Key。
- 每页条数位于调用明细标题旁，调整时立即刷新明细并回到第一页；沿用已经提交的时间和对象筛选，不偷带尚未提交的新筛选。失败时保留旧数据和旧条数。

缓存读写 tokens 没有可可靠统计的持久化字段，本次不生成虚构的零值。时间分桶使用固定经过时长，完整起止时间按浏览器本地时区显示；不把固定24小时冒充跨夏令时的自然日。

# 同名模型的失效路由目标

新增渠道或别名时，同一归一逻辑模型名会继续使用既有来源范围、超时和重试策略。若旧策略只允许已不再声明此模型的连接，新连接不会自动加入白名单，模型可能处于“已启用，暂无可用连接”。这不表示映射未保存。

模型页在默认已启用视图提示当前分类中没有可用连接的已启用模型，并提供查看入口；卡片区分全局停用和没有可用连接。

“模型路由与回退约束”会列出仍在草稿中、但已不再声明此模型的目标。管理员可以逐项移除，再明确选择当前连接并保存。移除只修改草稿；关闭窗口会恢复已保存策略。空白名单与残留失效目标仍拒绝保存，不自动扩大来源范围。其他超时、重试、自动选择及本地分配字段保留。

已有单元回归覆盖失效目标发现、逐项移除与顺序/其他字段保持、移除最后目标后继续拒绝空范围，以及无路由模型的可发现性与状态文案。生产调整应在保留原策略其余字段的前提下明确替换来源，并读回确认；模型可显示和可路由不等同于真实上游推理、定价或计费已验收。

# 模型类型与参数驱动的价格配置

本轮按用户要求修正新建价格流程，不增加旧定价迁移，不修改模型配置或已有账目。

## 新建价格流程

统一“模型价格”入口：先选择已启用模型与实际来源渠道，再显示匹配的计价字段。无需预先选择 Token、按量或按次分类。

|模型类型|价格字段|
|---|---|
|对话／推理|输入、输出元／百万 Token|
|向量／重排|输入元／百万 Token，生成输出自动为零|
|语音识别 ASR|元／音频秒、分钟或小时|
|语音合成 TTS|按供应方实际字符或 UTF-8 字节选择|
|图像|元／张图|
|视频|按供应方实际选择元／段、秒、分钟或小时|
|工具|元／次|
|类型未配置|明确选择计价方式，不默认当作文本模型|

计价优先采用显式配置的模型展示用途，其次读取执行类型及对应上游目录。音频子类型仅在已有音频类型基础上结合明确 ASR／TTS 标识提供建议，不据名称更改模型类型。语音合成的字符／字节、视频的按段／时长若缺少供应方口径，不猜单位或价格。

Token 上限优先读取实际 OAuth／来源参数，并应用具体模型更小的上下文限制。已有参数显示为只读摘要；提交价格时不要求重复填写，由服务端使用当前参数。只有缺失项才显示“单次输入上限（Token）”“单次总输出上限（Token）”，并说明输入位置、预占、实际结算和多结果合计含义。

音频时长上限当前没有独立模型配置字段，只有确实无法读取时才补填，统一填写秒、精确到毫秒；单价仍按所选秒／分钟／小时换算。视频时长使用“视频”文案，不复用音频上限。更换模型、来源或单位清空相应旧输入，避免错误解释金额。

# 用量账本按时间查询与区间统计

管理员账本、普通用户“我的空间”均新增今天、本周、本月、自定义和全部时间。默认今天；预设按浏览器本地日历计算，本周从周一开始。自定义支持秒，起点包含、终点不包含。界面展示实际生效的起止时间；编辑筛选后提交查询，成功才更新结果。翻页、刷新沿用已提交范围。

接口 `/api/usage`、`/v1/usage`、`/api/account/portal` 接收可选 `start_at`、`end_at`（Unix 秒），按账本 `created_ms` 查询。无时间参数的既有客户端保留全时段语义。服务端校验负值、溢出与倒置区间。管理员原有用户、Key、接入、模型、对象状态筛选继续生效。普通用户门户固定本人，API Key 接口固定所属用户及 Key。

`summary` 统计全部匹配账本，不受 `before_id`、`limit` 影响：请求数按 request_id 去重、尝试账本数、已知输入/输出/合计 tokens、输入/输出未知记录数、未定价记录数、已知扣款和未知扣款记录数。总 tokens 是账本已知输入与输出之和，不把未知当零；不代表上游供应商对账结论。重试尝试仍按各笔实际账本累计用量。

数据库迁移 v46 新增时间与用户时间覆盖索引。无需搬迁或重写历史账目；首次升级创建索引需要额外磁盘和迁移时间。线上未部署本次变更。

源码基线为 `b0ae13a`，包含任务开始时已有的两处路由文件修改参与构建；此次提交只包含本功能文件，不包含那两处已有改动。构建测试固定在 build-test `/srv/build/tokengo-usage-period-20261113`，同步范围与文件哈希见 `evidence/source.json`。验证结果和命令收据见 `evidence/`；浏览器合成数据验证与生产验收分开记录。

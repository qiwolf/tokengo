汇率读取 ECB 每日参考数据，以 CNY/EUR ÷ USD/EUR 计算 USD/CNY，整数精度转换并持久缓存；成功缓存 6 小时，读取失败使用上次有效报价并标注状态，无报价时金额显示不可用，调用数及 tokens 继续完整展示。新价格及结算仍使用人民币。参考汇率用于报告展示，不表示实际外汇成交价。[ECB 数据说明](https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html)。

自定义时间为起止日期及可选起止时刻。日期不填默认今天，时刻不填覆盖所选日期全天，结束日期包含全天；选择时刻后按实际起止时间连续查询。删除图表下方逐小时选择器；图表仍自动汇总所选范围，不影响查询精度。日期有效性、闰年及范围倒置均有验证。

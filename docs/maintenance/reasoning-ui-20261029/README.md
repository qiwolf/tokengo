# 自定义推理档位与来源展示

范围：现有供应商模型的“推理设置”，未部署。保留既有视觉结构，增加明确的来源与人工模式。

- 来源分为上游声明、当前连接实测补充、内置兼容、人工设置；实测补充沿用已验证证据及身份边界，不将人工填写标记为实测。
- 跟随来源：清除人工列表，使用当前有效来源能力。追加：保留有效来源能力并合并人工值，刷新目录后动态合并。覆盖：仅允许人工列表，继续支持主动排除能力。
- 默认下拉随未保存的草稿实时变化；人工列表、模式与默认值一次PUT事务保存。默认值被移除时显示明确提示，提交前要求重新选择，不静默回落。none明确关闭推理，“沿用服务商默认”不补参数。
- 旧manual_levels JSON数组与省略manual_mode的旧请求仍按replace解释；append存为带mode/levels的对象，不改表结构。来源身份或上游映射变化后旧人工声明失效。
- DeepSeek已支持的原生别名在append下继续可用；replace仍可排除。网关前置校验与来源原生参数校验一致。
- 未来回退到不识别append对象的旧程序前，必须先将新增append配置转换为经确认的旧数组或清除人工设置；本次没有修改任何生产数据库。

验证：在build-test执行前端单元、推理能力回归、HTTP接口事务回归、WASM发行构建和真实构建产物的浏览器表单测试。浏览器使用隔离的模拟接口；不访问生产、不调用模型。日志、截图和源码哈希见交付输出。

结果：173项前端单元、26项推理能力回归、3项HTTP接口回归全部通过，WASM发行构建通过；隔离模拟接口上的真实产物浏览器检查通过。桌面1280×1000、窄屏390×844；窄屏scrollWidth=390，无页面横向溢出，无页面脚本错误。源码哈希与Mac一致。build-test日志和脱敏表单提交收据随本文本地提交，截图及web.tar.gz保存在项目outputs/reasoning-ui-20261029。

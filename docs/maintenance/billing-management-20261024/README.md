## 管理结构

账务按额度管理、价格配置、用量账本三个入口切换，每次只呈现当前维度。额度再分用户/Key，默认有效对象；历史对象显式切换且只读。价格分Token与按次、当前生效与历史版本；服务按次价格回到透传服务配置维护，不误走LLM调价API。账本保留历史，按用户、Key、上游名称筛选，内部编号放进详情。

预算管理支持设置/修改总限额、解除限额、冻结/恢复；前后端拒绝无效身份，保留已扣和预占并记审计。解冻时限额必须覆盖累计与在途额度，或解除限额。金额用USD显示，不使用浮点换算。

查询和分页独立：查询/重置在筛选区，最新一页/上一页/较早一页在列表底部。查询显示加载、完成时间、页码、条数和错误，失败保留旧结果。分页沿用已提交条件；末页无游标且禁用较早一页。当前占用只表示尚未结算的额度，结算后为0；初始预占留在原始详情，不混为未释放额度。未知费用不显示成免费。

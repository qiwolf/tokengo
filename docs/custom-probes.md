# 自定义探针

自定义探针供管理员检查一个明确接入，不借用普通用户或 VKey，也不修改正常路由的 fallback 健康状态。普通用户不能读写或执行探针。原有恢复探活仍遵循自己的规则，不能与本页能力混为一谈。

## 页面操作

在“探针”页选择新增，填写名称、供应方、凭据 / API 地址、本地模型及该接入支持的类型。通过表单配置输入、预期 HTTP 状态、内容包含或向量维度、延迟、超时及运行间隔；保存与取消分开，启停与删除为独立操作，不需要编辑 JSON。修改按版本检查，旧页面保存冲突返回 409，应刷新后重新核对。

支持 Chat、Responses、Messages、Embeddings、OpenAI OAuth Responses、独立 Search 和 Fetch。API 协议和工具能力以已保存配置为准，不按品牌或模型名称猜测。停用来源无法执行，但允许先停用探针以修复配置。

- OAuth 选择已绑定账号的接入，只提供 Responses；执行使用正常令牌刷新和账号认证链。订阅入口不支持普通输出 Token 参数，页面不显示该上限，使用超时和响应大小保护。
- 搜索提供查询词、结果数及是否返回网页正文等控件；网页提取填写 URL。独立工具仅提供真实启用的类型。本地模型用于计费归属，不作为工具请求体中的模型参数发送。
- 对话可检查内容，向量可检查维度；响应结构也必须符合所选类型。状态码符合不等于响应内容正确。

保存不立即调用上游。启用或更新后等待完整间隔才进行定时执行；停用后仍可显式手动执行一次。手动执行和定时执行均可能消耗供应商额度。

## 执行保护

最多 64 个探针；间隔 60–86400 秒，单次总期限 1–60 秒，响应读取上限 256 KiB。普通对话输出参数上限 1–256 Token；OAuth 订阅不适用此参数。来源 / Key 并发门及工具账号 QPS 与正常请求共享；同一探针租约防止重复运行。执行在发送前重新检查来源、凭据、模型、版本和归属，配置变化时拒绝过期请求。

删除或取消不会撤销已经发给供应商的请求。已发送但结果不完整时保留未知用量，不把未知改成零。探针直接检查指定接入，不切到另一个 Key 或模型来掩盖当前目标失败。

## 系统诊断账本

发送前建立诊断预约，执行后通过持久结算链记录来源、模型、认证/价格快照、Token 或请求单位及触发方式。账务显示“系统诊断”，不显示为某个普通用户的消费；不会扣普通用户额度。

Search / Fetch 使用请求次数，与 Token 计量分开。明确未发送为 0 次，发送后结果未知则保持未知。缺少价格和 OAuth 订阅 USD 成本均显示未知，不等于免费。这里没有新增管理员可配置的独立系统诊断总预算，也不承诺与供应商最终发票完全一致；频率、输出参数、超时和响应上限只是执行保护。

## 已验证范围

测试部署已通过三类实际调用：OAuth Responses、独立 Search、独立 Fetch；OAuth 曾因上游 MIME 标签与实际 SSE 不一致失败，修复后重验成功，原失败记录保留。新增/编辑/取消/启停、授权隔离及手机布局另有浏览器检查；三类探针删除通过 API 读回核对，本轮未重复宣称全部类型的 GUI 删除按钮已逐一重测。

合成测试覆盖格式、刷新、取消、共享并发/QPS、凭据归属变化、系统账本幂等及用户预算隔离。有限真实调用不等于所有模型、供应商、参数或持续可用性保证。分发构建状态见[验收状态](acceptance-status.md)。

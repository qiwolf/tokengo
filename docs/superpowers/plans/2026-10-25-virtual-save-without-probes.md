# 虚拟模型保存与验证解耦

用户要求：保存不调用上游、不等待推理检查；保存后可逐目标单独验证。

实施：共享/个人虚拟模型创建和编辑只做本地结构、授权、名称冲突及版本检查。保留运行时兼容性要求，未取得当前来源证据时明确显示待验证。列表提供单独的逐目标轻量诊断，以及独立的完整链兼容验证任务；完整链验证后台执行、版本绑定，不锁住编辑或保存。取消在后台自动首次执行重负载认证，已有证据的轻量续验保留。

逐目标诊断按已保存目标和当前授权枚举实际来源，每个来源独立报告成功/失败，失败不阻断其他来源；轻量诊断不冒充完整跨来源兼容认证，不改变配置或授权。完整验证继续使用既有合同逻辑。无有效合同的向量多目标调用维持明确拒绝，不隐式放行未验证回退。

验证：build-test 上先复现保存触发网络，再验证保存离线成功/无上游请求、版本冲突及越权拒绝；独立目标检查只访问选定来源、失败隔离；完整验证启动立即返回，既有运行时合同与续验回归。构建原生服务端与Web WASM。日志及产物取回本地review/bge-virtual-save-20261025。

源码与Git操作在Mac。完成后本地提交，不推送或公开发布；线上更新单独说明验收边界。

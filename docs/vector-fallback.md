# 向量与重排多目标回退

向量与重排按真实用途识别，不以 BGE 名称作白名单。多目标要求用途一致、各来源已授权，并建立来源身份及数值兼容证据。管理员共享入口可授权普通用户；底层模型可设为仅内部调用，用户不能绕过共享入口直接调用。

## 接收能力遵循真实模型

虚拟入口不再按兼容探针样本限制字符数、批量条数、候选数、查询长度或总字符数。原始文本、全部候选和供应商扩展参数完整转发，不截断、不丢候选。`max_chunks_per_doc`、`overlap_tokens` 等参数由实际后端判断；较小备用源不能使较大主源的请求在网关被提前拒绝。

向量支持文本、文本批次、token ID 数组和 token 批次，以及 float/base64 编码；显式维数按实际请求校验。重排支持字符串或含 text 的文档对象，`top_n` 控制返回数量，不减少送给模型的候选。正常响应检查完整索引、维数、有限数值、评分顺序和返回原文，防止损坏或数据遗漏。

直接及虚拟向量/重排端点共用 HTTP 正文资源预算，默认 64 MiB，可通过 `TOKENGO_VECTOR_BODY_LIMIT_BYTES` 配置字节数；反向代理预算须相应配置。虚拟响应读取与直接调用一致，取消原有 4 MiB 独有限制。用户额度、预算、来源权限和超时仍然生效，它们不等于模型本身的 token 窗口。

## 兼容检查是证据，不是容量上限

首次保存或显式升级 profile 会对所有来源执行轻量数值参考和完整合成负载：300 条/篇、每条 4096 Unicode 字符，重排请求返回全部候选和原文，向量检查首尾单条与批次映射。每源完整检查预算 270 秒，总预算按来源数计算；单个大负载请求最多 120 秒，探针响应预算 16 MiB。这些数字只描述验证样本及诊断资源，不限制正常调用。

向量跨来源比较余弦至少 0.999、范数比例差不超过 2%；重排按候选索引比较评分，容差 0.02，允许近同分名次交换，拒绝显著评分差的逆序。保存首次完整检查时间和输入/数值输出摘要。有限样本不能证明权重相同或所有业务数据上的结果相同；超过样本仍可正常请求真实后端。

兼容证据绑定用户、完整目标/来源集合、实际模型映射、地址、凭据版本、请求头、协议与输出配置。身份改变不能继承旧证据。上游在同一地址下改变内部运行参数或模型，应重新完整核验；仅有网关配置指纹无法即时发现全部语义变化。

## 回退、超时及日志

连接失败、超时、5xx、无效 JSON、错误维度或索引等故障按配置顺序尝试下一目标，每次重新检查权限、版本和预算并独立记账。普通 400/429 遵守显式开关；普通参数错误不能不加区分地重试。已识别的真实来源容量不足应原样尝试下一授权来源，不裁剪请求或将健康来源全局降级。所有来源均不能处理时保留实际拒绝原因。

按虚拟别名设置 `nonstream_timeout_ms` 与 `request_budget_ms`；长文不能沿用几秒的调用端超时。客户端总等待时间须覆盖计划中的回退预算。网关本地兼容/结构拒绝记录原始错误码、HTTP 状态、用户和 Key 身份及纯数字请求规模，不写输入原文，不创建上游尝试或扣费。

## 自动续验与失败恢复

启动时及每分钟扫描已启用的私有和共享策略。证据 24 小时有效，18 小时开始提前续验，失败每 5 分钟重试，无需每天手动保存。日常续验使用原有轻量数值参考，不重复发送 300 篇长文档；持久化租约 90 秒，单轮最多 60 秒。完整升级采用覆盖实际来源数及发布余量的更长租约。

来源失败只隔离该来源，健康且证据有效的来源继续服务；所有来源均不可用或全局证据损坏时才整体拒绝。旧 v1 证据仍可读取，但不再把旧样本范围套作正常接收限制。完整升级失败不覆盖仍有效且身份未变的旧证据，并显示升级失败原因；首次核验或身份变化不能仅凭一个来源签发整链证据。

私有诊断受所有者预算、额度和并发约束，共享诊断记管理员系统账。自动续验无法替代修复来源故障、权限或预算不足。完整能力与证据边界见[模型能力说明](vector-model-capabilities.md)；各批次实际通过结果以验收记录为准。

# 向量与重排多目标回退

向量与重排按真实用途识别，不以 BGE 名称作白名单。多目标要求用途一致、各来源已授权；来源身份及数值兼容检查仅为可选排错诊断，不是保存、正常调用或按配置回退的前置条件。管理员共享入口可授权普通用户；底层模型可设为仅内部调用，用户不能绕过共享入口直接调用。

## 接收能力遵循真实模型

虚拟入口不再按兼容探针样本限制字符数、批量条数、候选数、查询长度或总字符数。原始文本、全部候选和供应商扩展参数完整转发，不截断、不丢候选。`max_chunks_per_doc`、`overlap_tokens` 等参数由实际后端判断；较小备用源不能使较大主源的请求在网关被提前拒绝。

向量支持文本、文本批次、token ID 数组和 token 批次，以及 float/base64 编码；显式维数按实际请求校验。重排支持字符串或含 text 的文档对象，`top_n` 控制返回数量，不减少送给模型的候选。正常响应检查结果数量、唯一且有效的索引、维数、有限数值及要求返回的原文，防止损坏或数据遗漏。重排分数的排序及跨来源数值一致性属于可选诊断；运行时不会因为来源返回了不同评分顺序就拒绝正常结果。

直接及虚拟向量/重排端点共用 HTTP 正文资源预算，默认 64 MiB，可通过 `TOKENGO_VECTOR_BODY_LIMIT_BYTES` 配置字节数；反向代理预算须相应配置。虚拟响应读取与直接调用一致，取消原有 4 MiB 独有限制。用户额度、预算、来源权限和超时仍然生效，它们不等于模型本身的 token 窗口。

## 兼容检查是证据，不是容量上限

保存只校验配置并持久化，不发送上游检查。只有用户主动启动完整兼容诊断或显式升级 profile 时，才对所有来源执行轻量数值参考和完整合成负载：300 条/篇、每条 4096 Unicode 字符，重排请求返回全部候选和原文，向量检查首尾单条与批次映射。每源完整检查预算为 Embeddings 360 秒、Rerank 270 秒，总预算按来源数计算；单个大负载请求最多 120 秒，探针响应预算 16 MiB。这些数字只描述验证样本及诊断资源，不限制正常调用。

轻量向量参考跨来源比较余弦至少 0.999、范数比例差不超过 2%。完整长负载另测各来源重复请求的数值波动，以有界的归一化 L2 预算比较跨来源结果：单项预算最高 0.1，来源自身及跨来源整批最差配对平均余弦仍须至少 0.999，范数比例差不超过 2%；重排按候选索引比较评分，容差 0.02，允许近同分名次交换，拒绝显著评分差的逆序。保存首次完整检查时间和输入/数值输出摘要。有限样本不能证明权重相同或所有业务数据上的结果相同；超过样本仍可正常请求真实后端。

兼容证据绑定用户、完整目标/来源集合、实际模型映射、地址、凭据版本、请求头、协议与输出配置。身份改变不能继承旧证据。上游在同一地址下改变内部运行参数或模型，应重新完整核验；仅有网关配置指纹无法即时发现全部语义变化。

## 回退、超时及日志

私有及共享向量/重排入口遇到连接失败、超时、5xx、无效 JSON、错误维度或索引等故障，按已配置目标顺序尝试下一目标（目标内部可按 Key 池或本地节点策略选择来源，不按诊断结果或运行评分重排目标），每次重新检查权限、版本和预算并独立记账。普通 400/429 遵守显式开关；普通参数错误不能不加区分地重试。已识别的真实来源容量不足应原样尝试下一授权来源，不裁剪请求或将健康来源全局降级。所有来源均不能处理时保留实际拒绝原因。

按虚拟别名设置 `nonstream_timeout_ms` 与 `request_budget_ms`；长文不能沿用几秒的调用端超时。`nonstream_timeout_ms` 是非流式单次尝试超时，`request_budget_ms` 是含等待、重试和回退的整次调用预算；省略时继承全局值，显式值须为 1～3,600,000 毫秒。通过模型路由编辑器或 `PUT /api/model-routing?model=<虚拟入口名>` 配置，先读取并保留其余字段，因为 PUT 替换整个策略。使用本地节点轮询时，轮询读取目标逻辑模型的策略，超时读取实际调用的虚拟入口策略。客户端和反向代理总等待时间须覆盖计划中的回退预算。网关本地兼容/结构拒绝记录原始错误码、HTTP 状态、用户和 Key 身份及纯数字请求规模，不写输入原文，不创建上游尝试或扣费。

## 可选诊断与失败处理

向量与重排兼容诊断只在用户主动启动时执行。生产服务不在启动时或定时扫描触发 GPU 兼容探测，不自动续验，不自动重试诊断。完整诊断可在后台执行，期间可以继续编辑、保存、正常调用或离开页面。

未验证、验证失败、证据过期或缺少数值参考均不撤销已保存配置，不隔离来源、不暂停正常调用，也不改变用户配置的目标顺序和400/429回退开关。正常请求仍检查实时身份、权限、额度、预算、来源配置和实际响应完整性；真正的上游错误按调用策略处理。旧诊断记录可供排错，但不参与正常调用的放行或回退判定。

私有诊断受所有者预算、额度和并发约束，共享诊断记管理员系统账。诊断本身会产生上游负载，只在排错需要时主动执行。完整能力与证据边界见[模型能力说明](vector-model-capabilities.md)；各批次实际通过结果以验收记录为准。

## 配置顺序与授权

先在各供应方准备真实模型及上游映射，再在“调用策略”或“共享虚拟模型”中添加相同用途的目标。例如第 1 步云端 `bge-m3`、第 2 步本地 `bge-m3`；需要 GPU 优先则交换目标顺序。名称仅为示例，目标用途必须是 Embeddings 或 Rerank，不能混用。若本地目标有多个节点，给该目标的逻辑模型配置 `local_strategy: "round_robin"`，目标之间仍使用所设顺序。

按需求设置各目标的 400/429 切换开关，保存后即可用虚拟名调用。向量/重排的网络与结构故障自动回退不依赖这两个开关，也不依赖兼容诊断。私有聊天链的跨目标规则不同：仅显式允许的 400/429 触发；管理员共享链可对来源故障回退。详见[三层策略](provider-key-pools.md#三层策略账号节点虚拟目标)。

时段模式支持 `Asia/Shanghai`、`UTC`，使用周一至周日和半开时间区间。跨午夜分两段，同日区间不能重叠；命中时按该时段目标位置执行，未命中时使用默认链，默认链为空则拒绝。每次后续尝试会重新核对时段，已运行的尝试不会到点强行中断。

共享入口可委托“仅内部调用”模型；普通用户私有链不能绕过此限制。共享入口的模型授权与底层来源白名单分别生效。计费使用实际用户/VKey、真实来源和模型价格，未知 usage 或未定价状态须保留，不能因虚拟名、轮询或回退将其标记为免费。完整操作见[共享入口配置](shared-virtual-models.md#配置步骤)。

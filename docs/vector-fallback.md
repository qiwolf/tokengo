# 向量与重排多目标回退

普通用户在调用策略中按顺序选择云端和自有 GPU，再保存。向量与重排都适用，不以 BGE 或其他名称作白名单。单目标保持原有行为；多目标须用途一致、真实模型及每个渠道均已授权。

保存多目标策略会真实请求各目标下所有可用凭据/地址的上游，使用合成文本检查兼容性；会消耗上游调用量，按保存用户的预算、限流和诊断账本记录。缓存命中不重复推理。失败不保存策略，也不写成功证书。检查总时间最多60秒，单次最多15秒，响应最多4 MiB。

向量检查批次、完整且唯一的索引、有限非零数值、共同维度；相同文本跨来源余弦至少0.999、范数比例差不超过2%。重排检查文档数量、top_n、索引范围和唯一性、分数降序、有限分数以及返回文档对应关系；受测排序须一致，对应分数差不超过0.02。合成样本通过是有限范围的一致性证据，不能证明模型权重或所有业务数据上的结果相同。

证书绑定用户、完整目标/来源集合、实际模型映射、URL、凭据版本、请求头、协议和输出配置。改变这些配置后必须按新身份复核；系统在18小时开始自动续验、失败5分钟重试，不要求每24小时手动保存。过期且无已核实健康来源时拒绝调用，不静默放行。改变策略顺序或开关也可能需要复核。数据库中的证书由服务端签发，调用者不能通过请求 JSON 自行声明兼容。

已验证链在连接失败、超时、5xx、无效 JSON、错误向量维度或重排索引等故障时按所选顺序尝试下一目标，包括时段内的逆序链。400和429继续遵守各目标及上游凭据开关。每次尝试重新检查权限、配置版本和预算；每个真实来源独立记账。Chat 的既有切换规则保持不变。

当前自动核验的输入域如下，超出时返回明确错误，使用单目标模型可继续按其原有能力调用：

| 项目 | 已核验范围 |
| --- | --- |
| 向量输入 | 非空字符串，或1至16条字符串；每条最多512个Unicode字符；总计最多8192字符 |
| 向量编码 | 默认或显式 `float`；尚不支持 `dimensions`、`base64` 或 token ID 输入 |
| 重排输入 | 非空字符串 query 和1至128篇非空字符串 documents；query/每篇最多512字符，总计最多8192字符 |
| 重排参数 | `top_n` 为1至文档数，或省略；`return_documents` 为布尔值，或省略 |
| 其他参数 | 未受测的字段拒绝；模型名不能作为兼容性依据 |

每次业务响应还要通过结构和维度校验后才返回。长上下文差异不通过静默裁剪解决；上述字符范围也不是所有分词器和Unicode输入都等价的证明。若上游在不更换地址/凭据的情况下改变权重，样本证书不能即时发现所有语义漂移；配置指纹、到期复核和响应检查分别提供不同范围的保护。

## 自动续验与失败恢复

向量和重排多目标策略保存后，服务在启动时及每分钟扫描已启用的私有、管理员共享策略。兼容证据仍有 24 小时硬有效期，18 小时开始提前续验；无需每 24 小时手动保存。单目标及其他模型用途不产生兼容续验探测。

续验按用户域和当前来源指纹领取持久化 90 秒租约，一轮最长 60 秒；并发扫描和手动保存不会为同一指纹重复探测，重启后可在租约过期时恢复。来源、凭据、权限、策略版本在探测前和发布前复核。私有探测仍受真实所有者额度/预算/并发约束，共享探测记管理员系统诊断账。

续验逐来源与保存的合成数值/排序参考比较。来源不可用或不兼容仅隔离该来源，健康且身份未变的来源独立续签并继续服务；所有来源均不可用或全局证据损坏时才整体拒绝调用。系统每 5 分钟自动重试，来源恢复后按原顺序使用。首次及旧版无参考的完整初始化仍要求所有来源通过，且保留旧维度与归一化约束；不能只凭单个存活来源建立整链参考。手动保存不得借用降级状态跳过失败来源。若修改来源或权限使指纹变化，按新来源重新校验，不沿用旧凭证。调用策略列表显示最近通过、有效期、失败原因和下次重试时间，并每 30 秒刷新；失败调用返回 `vector_compatibility_renewal_failed`，HTTP 503。尚未完成或过期等待校验仍按原有兼容拒绝规则处理，提示系统将自动续验。

在上游持续不可用、所有者被停用、权限/预算不足或来源配置不兼容时，自动续验无法保证恢复；需要修正实际故障。系统不会通过自动续验放宽向量维度、数值一致性、重排排序及请求域约束。
